An immutable semantic version following the Semantic Versioning 2.0.0 specification. Supports parsing, comparison, and conversion operations for version strings in the format MAJOR.MINOR.PATCH[-PRERELEASE][+METADATA].

[PublicAPI]
public sealed class SemVer
Inheritance
object
SemVer

Examples

var version1 = SemVer.Parse("1.2.3-alpha.1+build.123");
SemVer version2 = "2.0.0";
bool isNewer = version2 > version1; // true

Remarks

This class implements semantic version comparison where:

  • Release versions (without pre-release) are greater than pre-release versions
  • Pre-release versions are compared lexicographically by dot-separated identifiers
  • Numeric identifiers in pre-release are compared numerically (of any length) and have lower precedence than alphanumeric identifiers
  • Metadata is used only as a final tiebreaker when all other components are equal

Create instances with Parse(string), TryParse(string?, out SemVer), FromSystemVersion(Version, bool) or the implicit conversion from string. The public parameterless constructor is obsolete: it always creates version 0.0.0 and cannot set components.

The type implements System.ISpanParsable<TSelf>, System.IComparable<T> and System.Numerics.IComparisonOperators<TSelf, TOther, TResult>, so it works with generic parsing, sorting and ordered collections.

System.Text.Json serializes a SemVer as an object with the Major, Minor, Patch, PreRelease and Metadata properties (null components are written as null) and deserializes it through a private constructor, without a custom converter. The computed properties Prefix, IsPreRelease, BuildNumberFromPreRelease and BuildNumberFromMetadata are not serialized.

Methods

CompareTo(SemVer?)

Compares the current instance with another SemVer and returns an integer that indicates whether the current instance precedes, follows, or occurs in the same position in the sort order.

public int CompareTo(SemVer? other)

Parameters

other SemVer

The SemVer to compare with this instance.

Returns

int

A value that indicates the relative order of the objects being compared: Less than zero if this instance precedes other; Zero if they are equal; Greater than zero if this instance follows other.

Remarks

Comparison follows Semantic Versioning precedence rules:

  1. Compare major, minor, and patch versions numerically
  2. Pre-release versions have lower precedence than normal versions
  3. Pre-release identifiers are compared left to right: identifiers consisting only of ASCII digits are compared numerically (of any length, without overflow), a numeric identifier has lower precedence than an alphanumeric one, and alphanumeric identifiers are compared ordinally (ASCII)
  4. When all shared identifiers are equal, the version with more pre-release identifiers is greater
  5. Metadata is used only as a final tiebreaker (ordinal comparison)

Any instance is greater than null, so this method returns a positive value when other is null.

ExtractBuildNumber(string?)

The numeric value if exactly one sequence of digits is found; otherwise, 0. Returns 0 if the input is null, empty, whitespace, or contains zero or multiple numbers.

FromSystemVersion(Version, bool)

Creates a SemVer instance from a System.Version.

public static SemVer FromSystemVersion(Version version, bool throwIfContainsRevision = false)

Parameters

version Version

The System.Version to convert.

throwIfContainsRevision bool

If true, throws an exception when the version has a revision greater than zero. Defaults to false.

Returns

SemVer

A SemVer with Major, Minor, and Patch (from Build) components and no pre-release or metadata.

Remarks

Maps System.Version Major.Minor.Build to SemVer Major.Minor.Patch. The revision component is ignored unless throwIfContainsRevision is true.

An undefined System.Version.Build (-1, as in new Version(1, 2)) maps to a Patch of 0, so the result is always a valid version that ToSystemVersion(bool, bool) can convert back.

Exceptions

ArgumentException

Thrown when throwIfContainsRevision is true and System.Version.Revision is greater than zero.

IsBetween(SemVer, SemVer)

Determines whether the current version is between two specified versions (exclusive).

public bool IsBetween(SemVer firstBound, SemVer secondBound)

Parameters

firstBound SemVer

The first boundary version.

secondBound SemVer

The second boundary version.

Returns

bool

true if this version is strictly between the two bounds; otherwise, false.

Examples

var version = SemVer.Parse("1.5.0");
version.IsBetween("1.0.0", "2.0.0"); // true
version.IsBetween("2.0.0", "1.0.0"); // true (bounds in any order)
version.IsBetween("1.0.0", "1.5.0"); // false (bounds are exclusive)

Remarks

Both bounds are exclusive and may be supplied in any order; the lower one is determined with the same precedence rules as CompareTo(SemVer?), so pre-release and metadata in the bounds are respected.

If both bounds are equal, returns true only if this version equals the bounds.

ToString()

Returns the string representation of this semantic version.

public override string ToString()

Returns

string

A string in the format MAJOR.MINOR.PATCH[-PRERELEASE][+METADATA], where the pre-release and metadata components are included only if present.

Examples

SemVer.Parse("1.2.3").ToString();               // "1.2.3"
SemVer.Parse("1.2.3-alpha").ToString();         // "1.2.3-alpha"
SemVer.Parse("1.2.3+build.1").ToString();       // "1.2.3+build.1"
SemVer.Parse("1.2.3-alpha+build.1").ToString(); // "1.2.3-alpha+build.1"

Remarks

For a version obtained by parsing, the result round-trips: parsing it again with Parse(string) produces an equal version.
